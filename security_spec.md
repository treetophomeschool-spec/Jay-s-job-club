# Security, Human-AI Alignment & GDPR Specification — Jay's Job Club

## 1. Data Invariants, Safeguarding & Master Source of Truth
1. **Zero PII Storage (UK/EU GDPR Art. 5(1)(c) Data Minimisation & Art. 25 Privacy by Design):** None of the 24 collections/subcollections (`/publicProfiles/{userId}`, `/communityPosts/{postId}`, `/canopyStudios/{userId}`, `/journalEntries/{entryId}`, `/treeProgress/{userId}`, `/toolsOfTrade/{toolId}`, `/storeListings/{listingId}`, `/serviceProviders/{providerId}`, `/artisanItems/{itemId}`, `/privacyConsents/{userId}`, `/admins/{adminId}`, `/treetopApplications/{applicantId}`, `/pgCertNotes/{noteId}`, `/canopyWorkshops/{workshopId}`, `/canopyWorkshops/{workshopId}/registrations/{attendeeId}`, `/canopyWorkshops/{workshopId}/overflowAccess/{detailId}`, `/interestPathways/{pathwayId}`, `/craftedBottles/{bottleId}`, `/canopyPaypalItems/{itemId}`, `/shoeCharacters/{userId}`, `/chillPodOccupancy/{podId}`, `/jobCentreVacancies/{vacancyId}`, `/jobCentreVacancies/{vacancyId}/collaborators/{memberId}`, or `/uxBetaFeedback/{feedbackId}`) may contain `email`, `phone`, `address`, `ipAddress`, or shadow keys (`hasOnly` enforced on every collection).
2. **Human-in-the-Loop Treetop Token Entry Gate (`/treetopApplications/{applicantId}`):**
   - Applicants can only create or resubmit their own `/treetopApplications/$(request.auth.uid)` with `status == 'pending'`, `treetopTokenGranted == false`, `tokenCode == ''`, and `adminNote == ''`. Self-approval or self-minting a Treetop Token is mathematically impossible.
   - Only a verified Administrator (`request.auth.token.email_verified == true && request.auth.token.email == 'treetophomeschool@gmail.com'` or `/admins/$(request.auth.uid)`) can transition `status` to `'approved'` and grant `treetopTokenGranted == true` with a valid `^TTK-[A-Z0-9\-]+$` code.
   - Anyone without `hasApprovedTreetopToken()` is blocked from creating/booking `/canopyWorkshops` or reading external overflow access.
3. **PG Cert Autism & Mental Health Student-in-Training Notes (`/pgCertNotes/{noteId}`):**
   - Strictly typed reflective curriculum notes (`moduleTheme` enum, `studyReflection` 20..3000 chars, `practiceTakeaway` 10..600 chars). `'archived'` is terminal for non-admin updates.
4. **33m Canopy Workshop Rota & Parent/Carer/Competent Adult Overflow Safeguarding (`/canopyWorkshops/{workshopId}` + Subcollections):**
   - **Master Gate (Pillar 1):** Every operation on `/registrations/{attendeeId}` and `/overflowAccess/{detailId}` verifies the parent `/canopyWorkshops/$(workshopId)` exists and is active (`status == 'scheduled'`).
   - **Adult Approval Invariant:** In `/registrations/{attendeeId}`, if `wantsSocialOverflow == true` (for Zoom, Facebook, or other social media overflow), `adultApprovalConfirmed` MUST be `true`, `appropriatenessConfirmed` MUST be `true`, and `adultApprovalType` MUST be one of `['Self (Competent Adult 18+)', 'Parent Approval Confirmed', 'Carer Approval Confirmed', 'Competent Adult Supporter Confirmed']`.
   - **Split-Collection Overflow Isolation (Pillar 6):** External Zoom/Facebook/Social Media join instructions live exclusively in `/canopyWorkshops/{workshopId}/overflowAccess/details` (`allow list: if false`), readable ONLY when the requester holds an Admin-approved Treetop Token AND has an active `registered` booking with `wantsSocialOverflow == true && adultApprovalConfirmed == true && appropriatenessConfirmed == true` (or is the workshop host/admin).
5. **Ground Entry Kiosk Personal Special-Interest-to-Job Dashboard (`/interestPathways/{pathwayId}`):**
   - Strictly private owner-only (`existing().uid == request.auth.uid`, with `isAdmin()` oversight on single-doc operations). Enforces `specialInterest` (2..120 chars), `potentialJobRole` (2..120 chars), `tradeTrack` enum, `readinessStage` enum, `comfortableNextStep` (0..360 chars), immutable `uid` & `createdAt`, and owner-enforced `allow list` (`existing().uid == request.auth.uid`).
6. **Tools of the Trade & Bottled/Labelled Agarwood Essential Oil Studio (`/toolsOfTrade/{toolId}` & `/craftedBottles/{bottleId}`):**
   - `ToolOfTrade` supports `'Botanical & Essential Oils'` plus `'agarwood_alembic_still'` and `'amber_bottling_kit'` 3D visual slots.
   - `CraftedBottleListing` (`/craftedBottles/{bottleId}`) enforces maker identity (`makerId == request.auth.uid`), parent `publicProfiles/$(makerId)` existence (`exists` or `existsAfter`), bounded label strings (`labelHeadline` 2..40, `labelBatchNote` 2..80, `barkOriginAndProcess` 10..500), discrete `bottleSizeMl in [5, 10, 15, 30]`, `saleVenue in ['welcome_area', 'canopy', 'both']`, bounded `pricePence` (`300..50000`) & `priceTokens` (`1..50`), terminal `'archived'` state lock for non-admins, and rule-enforced `allow list` (`existing().status == 'on_sale' || existing().makerId == request.auth.uid`).
7. **33m Canopy PayPal Maker Store (`/canopyPaypalItems/{itemId}`):**
   - Enforces seller identity (`sellerId == request.auth.uid` on create, immutable on update), parent `publicProfiles/$(sellerId)` existence (`exists` or `existsAfter`), bounded title (3..80), `tradeCategory` enum (6 Canopy trades including `'Botanical & Essential Oils'`), `materialsSpec` (5..200), `craftStory` (10..600), `sellerBenchTag` (0..50), `priceCents` (`300..250000`), `stockCount` (`0..100`), terminal `'archived'` state lock for non-admins, tiered update branches (Seller edit, Seller archive, or Verified Buyer stock decrement), and rule-enforced `allow list` (`existing().status == 'active' || existing().sellerId == request.auth.uid`).
8. **0m Welcome Area Shoe & Wellington Boot Characters (`/shoeCharacters/{userId}`):**
   - Strictly owner-isolated (`userId == request.auth.uid`, `allow list: if false`). Enforces `shoeKind` enum (`wellington_boots`, `safety_wellington_boots`, `steel_toe_work_boots`, `artisan_work_shoes`, `timber_rigger_boots`, `canvas_maker_shoes`), `colorway` enum (6 colourways), `characterNickname` (2..36 chars), immutable `uid` & `createdAt`, and `updatedAt == request.time`.
9. **33m Mezzanine Private Sensory Chill Pods (`/chillPodOccupancy/{podId}`):**
   - Restricted to discrete pod IDs `['pod_1', 'pod_2', 'pod_3', 'pod_4']`. Enforces strict **one-person-per-pod** occupancy: a verified user can only claim a pod when `existing().occupancyStatus == 'vacant'` (or stale `request.time > existing().updatedAt + duration.value(2, 'h')`). Only the active occupant (`existing().occupantId == request.auth.uid`) can toggle sensory settings (`fanEnabled`, `heaterEnabled`, `lightsOffCalm`, `flotationEnabled`, `quiltType in ['none', 'vegan', 'natural_duck_feather']`) or vacate the pod (which resets `occupantId == ''` and all sensory switches off).
10. **Old-Style Heritage Job Centre Board & Multi-User Collaboration (`/jobCentreVacancies/{vacancyId}` + `/collaborators/{memberId}`):**
    - `JobCentreVacancy` enforces `referenceCode` (`^JC-[A-Z0-9\-]+$`), `jobTitle` (3..90), `tradeCategory`, `locationZone`, `pacingStyle`, `collaborationMode`, `rewardTokens` (`1..15`), `creatorId == request.auth.uid` with `publicProfiles/$(creatorId)` existence check, terminal `'archived'` state lock, and rule-enforced `allow list` (`existing().status in ['open', 'filled'] || existing().creatorId == request.auth.uid`).
    - Subcollection `/collaborators/{memberId}` enforces Pillar 1 Master Gate (`exists(/jobCentreVacancies/$(vacancyId))` with `status == 'open'` and `collaborationOpen == true` on create), `memberId == request.auth.uid`, bounded `pledgeNote` (4..280), `collabRole` & `preferredStation` enums, and zero-DB-read `allow list`.
11. **Public Beta UX Testing Feedback (`/uxBetaFeedback/{feedbackId}`):**
    - Enforces verified tester identity (`authorId == request.auth.uid`), bounded `testerHandle` (2..40), `focusArea` enum, `easeScore` (`1..5`), `workedWell` (4..600), `improvementIdea` (0..600), and owner-or-admin read isolation (preventing cross-tester scraping).
12. **Daily Mastery Habit Tracker & Tree-Climbing Energy Points (`/dailyHabitTrackers/{userId}`):**
    - Strictly owner-and-admin isolated (`userId == request.auth.uid || isAdmin()` on `get`, `allow list: if false`). Enforces `uid == userId && uid == request.auth.uid`, `activeDate` (`^[0-9]{4}-[0-9]{2}-[0-9]{2}$`), `energyPoints` (`0..99999`), `lifetimeEnergyEarned` (`0..999999`), `totalMilestonesLogged` (`0..99999`), `dailyStreak` & `bestStreak` (`0..99999`, `bestStreak >= dailyStreak`), bounded `completedIdsToday` (`size() <= 10`, allowlist `focus_15m`, `community_outreach`, `job_slip_step`, `skill_practice`, `sensory_pacing`, `custom_1`..`custom_5`), bounded `customHabitLabels` (`size() <= 5`, string size `2..60`), `lastMilestoneLabel` (`0..80`), immutable `uid` & `createdAt`, and `updatedAt == request.time`.
13. **Verified Identity, Zero-DB-Read Static Short-Circuiting & Query Enforcement:** All writes require `request.auth != null && request.auth.token.email_verified == true`, `createdAt == request.time` (immutable on update), and `updatedAt == request.time`. Static `isValid*()` functions execute zero `get()`/`exists()` calls so invalid payloads short-circuit at zero billing cost, and every `allow list` rule evaluates `existing()` directly with zero `get()`/`exists()` calls.

## 2. The "Dirty Dozen" Adversarial Payloads
1. **Self-Granted Treetop Token Escalation:** Applicant creates `/treetopApplications/bob_uid` with `status: 'approved'` and `treetopTokenGranted: true` -> **DENIED**.
2. **Unverified Admin Email Spoof:** Attacker with `email: 'treetophomeschool@gmail.com'` but `email_verified: false` attempts to approve a Treetop Token application -> **DENIED**.
3. **Treehouse Canopy Entry Without Treetop Token:** User with `'pending'` application attempts to register in `/canopyWorkshops/ws_1/registrations/bob_uid` -> **DENIED**.
4. **Social/Zoom Overflow Without Adult Approval:** Approved Treetop Token holder submits `wantsSocialOverflow: true` with `adultApprovalConfirmed: false` or `adultApprovalType: 'Not Requesting External Overflow'` -> **DENIED**.
5. **Unauthorized External Overflow Link Scrape:** Token holder who has NOT confirmed adult approval attempts `getDoc` on `/canopyWorkshops/ws_1/overflowAccess/details` -> **DENIED**.
6. **Cross-User Private Journal, Consent, Interest Pathway, Shoe Character, UX Feedback, Daily Habit Tracker & Unapproved Application Read:** Bob attempts `getDoc` on Alice's `JournalEntry`, `PrivacyConsent`, `SpecialInterestPathway`, `ShoeCharacterProfile`, `UxBetaFeedback`, `DailyHabitTracker`, or `TreetopApplication` -> **DENIED**.
7. **Shadow Field / PII Injection on Create:** Valid `TreetopApplication`, `SpecialInterestPathway`, `CraftedBottleListing`, `CanopyPaypalItem`, `ShoeCharacterProfile`, `ChillPodState`, `JobCentreVacancy`, `UxBetaFeedback`, `DailyHabitTracker`, or `PgCertNote` plus `"email": "leak@example.com"` -> **DENIED** (`hasOnly` fails).
8. **Chill Pod Intrusion (1-Per-Person Violation) & Arbitrary Pod Creation:** Bob attempts to enter or toggle switches in `/chillPodOccupancy/pod_1` while Alice actively occupies it, or attempts to create `/chillPodOccupancy/pod_99` -> **DENIED**.
9. **Orphaned Subcollection Registration / Job Collaborator or Orphaned Store Listing (Master Gate):** Creating `/canopyWorkshops/nonexistent_ws/registrations/alice_uid`, `/jobCentreVacancies/nonexistent_jc/collaborators/bob_uid`, `/jobCentreVacancies` collaboration when `collaborationOpen == false`, or store items without `publicProfiles/$(uid)` -> **DENIED**.
10. **Self-Purchase or Stock Inflation on Canopy PayPal Store / Habit Energy Overflow:** Buyer attempts to increase `stockCount` or mutate `priceCents` on Alice's `/canopyPaypalItems` listing, Seller attempts self-buy on `StoreListing`, or user injects `energyPoints: 9999999` or unknown habit ID into `/dailyHabitTrackers` -> **DENIED**.
11. **Terminal State Bypass:** Non-admin attempts to edit an `'archived'` `PgCertNote`, `'archived'` `CraftedBottleListing`, `'archived'` `CanopyPaypalItem`, `'archived'` `JobCentreVacancy`, `'cancelled'` `CanopyWorkshop`, or `'cancelled'` `StoreListing` -> **DENIED**.
12. **Immutable `createdAt` Mutation & Unfiltered List Scrape:** Mutating `createdAt` on update or listing `/interestPathways`, `/craftedBottles`, `/canopyPaypalItems`, `/jobCentreVacancies`, `/uxBetaFeedback`, `/dailyHabitTrackers`, or `/shoeCharacters` without valid `where` filter -> **DENIED**.

## 3. Red Team Audit & Conflict Report
- **`/admins/{adminId}`**: Zero PII, writable only by verified bootstrap admin, `allow list: if false`.
- **`/treetopApplications/{applicantId}`**: Blocks self-approval (`status == 'pending' && treetopTokenGranted == false` for applicants); Admin approval restricted to `isAdmin()`; `isValidTreetopApplication(incoming())` wraps `allow update`.
- **`/pgCertNotes/{noteId}`**: Enforces curriculum enum & size bounds, terminal `'archived'` lock (with `isAdmin()` override), `isValidPgCertNote(incoming())` wraps `allow update`.
- **`/canopyWorkshops/{workshopId}`**: Requires `hasApprovedTreetopToken() || isAdmin()` to create/host; terminal `'completed'`/`'cancelled'` lock; `isValidCanopyWorkshop(incoming())` wraps `allow update`.
- **`/canopyWorkshops/{workshopId}/registrations/{attendeeId}`**: Pillar 1 Master Gate checks parent workshop; requires `hasApprovedTreetopToken()`; enforces Parent/Carer/Competent Adult approval boolean & enum invariants; `isValidWorkshopRegistration(incoming())` wraps `allow update`.
- **`/canopyWorkshops/{workshopId}/overflowAccess/{detailId}`**: `allow list: if false`; `allow get` enforces parent active check + `hasApprovedTreetopToken()` + verified adult-approved registration.
- **`/interestPathways/{pathwayId}`**: Enforces Identity Integrity (`data.uid == request.auth.uid || isVerifiedAdminEmail()`), strict `hasAll`/`hasOnly` keys, `.size()` bounds on every string, owner-only `allow list`, immutable `uid` & `createdAt`, and `isValidInterestPathway(incoming())` wrapping `allow update`.
- **`/craftedBottles/{bottleId}`**: Zero-DB-read static validation (`isVerifiedAdminEmail()` instead of `isAdmin()` inside static helper), `publicProfiles/$(makerId)` relational check on create, discrete `bottleSizeMl`, terminal `'archived'` lock, rule-enforced `allow list`, and `isValidCraftedBottle(incoming())` wrapping `allow update`.
- **`/canopyPaypalItems/{itemId}`**: Enforces `sellerId == request.auth.uid` on create, `publicProfiles/$(sellerId)` relational check, strict `hasAll`/`hasOnly` keys, `priceCents` (`300..250000`), `stockCount` (`0..100`), tiered update actions, terminal `'archived'` lock, and rule-enforced `allow list`.
- **`/shoeCharacters/{userId}`**: Enforces `uid == userId && uid == request.auth.uid`, `allow list: if false`, strict `hasAll`/`hasOnly` keys, `shoeKind` & `colorway` enums, `characterNickname` (2..36 chars), immutable `uid` & `createdAt`, and `isValidShoeCharacterProfile(incoming())` wrapping `allow update`.
- **`/chillPodOccupancy/{podId}`**: Enforces discrete `podId in ['pod_1', 'pod_2', 'pod_3', 'pod_4']`, strict 1-per-person occupancy lock (blocks second user while occupied < 2h), `quiltType in ['none', 'vegan', 'natural_duck_feather']`, full sensory reset on vacate, zero-DB-read `allow list`, and `isValidChillPodState(incoming())` wrapping `allow update`.
- **`/jobCentreVacancies/{vacancyId}` & `/collaborators/{memberId}`**: Enforces `^JC-[A-Z0-9\-]+$` reference codes, `publicProfiles/$(creatorId)` relational gate, terminal `'archived'` lock, rule-enforced `allow list`, and Pillar 1 Master Gate on `/collaborators/{memberId}` verifying parent vacancy is `'open'` and `collaborationOpen == true`.
- **`/uxBetaFeedback/{feedbackId}`**: Enforces verified `authorId == request.auth.uid`, `easeScore in 1..5`, strict string bounds, and owner-or-admin read isolation.
- **`/dailyHabitTrackers/{userId}`**: Enforces `uid == userId && uid == request.auth.uid`, `allow list: if false`, strict `hasAll`/`hasOnly` keys, `activeDate` regex `^[0-9]{4}-[0-9]{2}-[0-9]{2}$`, `energyPoints` (`0..99999`), `lifetimeEnergyEarned` (`0..999999`), bounded `completedIdsToday` allowlist (`<= 10`), bounded `customHabitLabels` (`<= 5` with element size checks), immutable `uid` & `createdAt`, and `isValidDailyHabitTracker(incoming())` wrapping `allow update`.
- **Existing 10 Core Collections (`publicProfiles`, `communityPosts`, `canopyStudios`, `journalEntries`, `treeProgress`, `toolsOfTrade`, `storeListings`, `serviceProviders`, `artisanItems`, `privacyConsents`)**: Preserved in full with zero-DB-read static validation, strict `hasOnly`, size limits, owner isolation, and GDPR Art. 17 erasure.
